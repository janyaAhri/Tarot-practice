# ไพ่ทาโรต์ — โต๊ะดูดวงแม่หมอ (สื่อกลางสำหรับโรลเพลย์)

หน้าตาแบบแอปบน iOS ใช้เป็น "โต๊ะไพ่" ให้ผู้ถามหยิบไพ่เอง
ส่วนการตีความเป็นหน้าที่ของ **แม่หมอ** (ตัวละครในแชท / ตัวคุณเอง)
repo นี้ไม่ตีความแทน แค่แสดงไพ่ เก็บความหมายไว้ให้เปิดดู และส่งบอกแม่หมอว่า "ผู้ถามเปิดได้ใบอะไร"

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ (ไม่ต้องติดตั้ง) บนมือถือจะเต็มจอ บนคอมจะเป็นกรอบมือถือตรงกลาง

1. **ตั้งค่า** (ไอคอนขวาบน): ชื่อผู้ถาม คำถาม หัวข้อ จำนวนใบ 1/3/5/7 และรูปแบบการวาง
2. เลื่อนกองไพ่ที่กรีดเป็นพัดด้านล่างซ้าย–ขวา **แตะเพื่อยกไพ่ แตะซ้ำเพื่อหยิบ** ไพ่จะบินไปวางบนโต๊ะตามตำแหน่ง
3. หยิบครบแล้ว **แตะไพ่บนโต๊ะเพื่อเปิดทีละใบ** (หรือกด "เปิดทุกใบ")
4. เปิดแล้วจะมี sheet ความหมายขึ้นมา: สลับ **ตั้งตรง/กลับหัว**, **ย่อ/เต็ม**, และจด **ความหมายของฉัน**
5. ทุกครั้งที่เปิด ระบบส่งข้อความเข้าแชทให้แม่หมออ่าน (ดูหัวข้อถัดไป)

บนหน้าไพ่แต่ละใบจะมีชื่อ ชื่อไทย และคีย์เวิร์ดย่อ เช่น `การเริ่มต้น / ความเสี่ยง`

## การส่งไพ่เข้าแชท (TarotBridge)

ข้อความที่ส่งมีแค่ข้อเท็จจริง เช่น

```
[เริ่มดูดวง] ผู้ถาม: คุณมิน | คำถาม: เขาจะกลับมาไหม | หัวข้อ: ความรัก | รูปแบบ: อดีต – ปัจจุบัน – อนาคต (3 ใบ)
[ไพ่ที่เปิด] ใบที่ 1/3 ตำแหน่ง “อดีต” (ที่มาของเรื่อง ...): The Fool / คนเดินทาง — ตั้งตรง
```

ในตั้งค่าเลือกได้ว่าจะส่งตอนเปิดทีละใบหรือรวมตอนเปิดครบ จะใส่คีย์เวิร์ด ความหมายเต็ม หรือโน้ตของผู้ใช้ด้วยไหม
และเติมข้อความกำกับท้ายได้ (เช่น "แม่หมอช่วยตีความ")

ส่งออกพร้อมกันหลายช่องทาง เลือกใช้ตามที่คุณฝังหน้านี้:

| ช่องทาง | ใช้เมื่อ |
|---|---|
| `window` event `tarot:reveal` | โค้ดอยู่หน้าเดียวกัน (userscript / extension) `addEventListener('tarot:reveal', e => e.detail.text)` |
| `postMessage` `{type:'tarot-reveal', text, meta}` | ฝังหน้านี้ใน `<iframe>` |
| `BroadcastChannel('tarot-bridge')` | เปิดคนละแท็บแต่โดเมนเดียวกัน |
| ใส่ลงช่องพิมพ์ของแชทตรงๆ | ใส่ CSS selector ของช่องพิมพ์และปุ่มส่งในตั้งค่า → ขั้นสูง |
| คัดลอกลงคลิปบอร์ด | เปิดสวิตช์ "คัดลอกอัตโนมัติ" |

ดูข้อความที่เคยส่งทั้งหมดได้ที่ ตั้งค่า → ดูข้อความที่ส่งแล้ว (คัดลอกซ้ำได้) และกด "ทดสอบส่งข้อความ" เพื่อลองต่อระบบ

## ข้อมูลและโน้ต

```
index.html
css/style.css
js/ui.js        sheet แบบ iOS, toast, หน้าตาไพ่
js/table.js     โต๊ะวางไพ่ กองพัด การหยิบ การสับ การเปิด
js/panels.js    sheet ความหมาย / ตั้งค่า / คลังไพ่ / สมุดโน้ต / ประวัติ
js/reading.js   สร้างข้อความ "ผู้ถามเปิดได้อะไร"
js/bridge.js    ส่งข้อความออกไปยังแชท
js/store.js     เก็บค่าตั้งและโน้ตในเครื่อง (localStorage)
data/cards.js            ชื่อ + คีย์เวิร์ดย่อ 78 ใบ
data/meanings-major.js   ความหมายเต็มไพ่ใบใหญ่ (รัก/งาน/เงิน ตั้งตรง-กลับหัว)
data/meanings-minor.js   ความหมายเต็มไพ่ใบเล็ก
data/spreads.js          รูปแบบการวางและความหมายของแต่ละตำแหน่ง
```

- **โน้ตของฉัน** จดแยกตั้งตรง/กลับหัวต่อไพ่ 1 ใบ เก็บในเครื่องอัตโนมัติ ส่งออก/นำเข้าเป็นไฟล์ได้ที่ "สมุดโน้ต"
- **แก้ความหมาย** ได้ที่ `data/*.js` โดยตรง อยากให้ตรงกับสำนักหรือโลกในพล็อตก็เขียนทับได้เลย
- **เพิ่มรูปแบบการวาง** copy บล็อกใน `data/spreads.js` แล้วกำหนดตำแหน่งด้วย `c` (คอลัมน์) กับ `r` (แถว)

## หมายเหตุเรื่องเนื้อหา

ความหมายไพ่ในไฟล์ข้อมูลเขียนขึ้นจากแนวทางการอ่านไพ่ Rider–Waite ทั่วไป
**ไม่ได้คัดลอกหรือดึงมาจากเว็บไซต์ใดโดยเฉพาะ** หากต้องการอ้างอิงเว็บใดเป็นหลัก ให้เทียบแล้วแก้ใน `data/` ได้เลย
